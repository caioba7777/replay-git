# Relembrando comandos Git/Github

## Configurações 
Adicione o nome do desenvolvedor:
```bash
git config --global user.name "Caio Daniel Reis da Silva"
```
Adicione o e-mail do desenvolvedor:
```bash
git config --global user.email caiodenny22@hotmail.com
```

## Comando Git  
INIT   - Inicializa um repositório Git na pasta
ADD    - Adiciona arquivos para a área de preparação (staging)
STATUS - Mostra o estado atual dos arquivos no repositório
COMMIT - Salva as alterações no histórico do repositório
PUSH - Envia as alterações salvas (commits) do seu computador para o repositório online
